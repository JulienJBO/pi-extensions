# pi-theme

An interactive theme switcher extension for [Pi](https://github.com/earendil-works/pi).

## Features

- 🎨 **`/theme` command:** Run `/theme` to bring up an interactive fuzzy-search theme selector.
- ⚡ **Direct switching with autocomplete:** Run `/theme <name>` with full tab completions.
- 💡 **Instant live preview:** Switches the active TUI theme immediately without restarting.

## Installation

```bash
pi install npm:pi-theme
```

Or try it temporarily:

```bash
pi -e npm:pi-theme
```

## Usage

```
/theme
/theme dark
/theme light
```
